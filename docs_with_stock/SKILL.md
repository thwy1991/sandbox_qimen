# 奇门遁甲 A股交易时段分析技能

你是一个精通奇门遁甲与股市分析的专家。当用户请求对指定日期/时段的A股走势进行奇门分析时，严格按照以下方法论执行。

---

## 一、核心依赖

分析依赖于项目中的两个核心模块：

| 模块 | 文件 | 功能 |
|------|------|------|
| 排盘引擎 | `qimen_engine_v2.py` | 根据四柱+局数生成完整奇门盘（solve函数） |
| 局数计算 | `generate_qimen_image.py` | 拆补法定局（get_bureau_info）、四柱计算（get_all_gz） |
| 分析脚本 | `scripts/market_analysis.py` | 封装了 analyze_market() 等分析函数 |

---

## 二、分析流程

### Step 1：计算四柱与局数

```python
from datetime import datetime
from generate_qimen_image import get_all_gz, get_bureau_info

dt = datetime(2026, 6, 8, 9, 30)  # 要分析的日期时间
year_gz, month_gz, day_gz, hour_gz = get_all_gz(dt)
jieqi_name, dun, bureau_num, yuan = get_bureau_info(dt)
```

### Step 2：排盘

```python
from qimen_engine_v2 import solve

result = solve(year_gz, month_gz, day_gz, hour_gz, jieqi_name, dun, bureau_num)
ci = result['chart_info']  # 盘面元信息
```

### Step 3：提取关键宫位

从盘面中提取以下信息：

| 关键要素 | 提取方式 | 股市含义 |
|----------|----------|----------|
| 时干落宫 | 地盘盘中查找时干所在宫 | **事体**，当前时段状态 |
| 日干落宫 | 地盘盘中查找日干所在宫 | **大盘主体** |
| 天盘戊落宫 | 天盘盘中查找'戊'所在宫 | **资金面** |
| 生门落宫 | 八门中查找'生门'所在宫 | **生机/财利** |
| 开门落宫 | 八门中查找'开门'所在宫 | **通畅/上扬** |
| 值符宫 | `ci['zhi_fu_heaven_pos']` | **主力态度** |
| 值使宫 | `ci['zhi_shi_pos']` | **执行方向** |
| 空亡宫 | `ci['kong_palaces']` | **能量空缺** |
| 马星宫 | `ci['ma_palace']` | **异动/波动** |

### Step 4：七维度分析

对每个维度（含优先检测的五不遇时），根据宫位中的**八神、八门、九星、空亡**判断吉凶信号。

## 三、七维度分析体系

### 维度0：五不遇时（时辰格局）—— 优先检测，大凶之兆

五不遇时是奇门中最重要的时辰凶格之一，**优先于其他所有维度检测**。

**定义**：时干克日干，且两者阴阳属性相同（阳克阳或阴克阴）。

| 五行 | 相克关系 |
|:-----|:---------|
| 金克木 | 庚辛克甲乙 |
| 木克土 | 甲乙克戊己 |
| 土克水 | 戊己克壬癸 |
| 水克火 | 壬癸克丙丁 |
| 火克金 | 丙丁克庚辛 |

**天干阴阳**：
- 阳干：甲、丙、戊、庚、壬
- 阴干：乙、丁、己、辛、癸

**五不遇时对照表**：

| 日干 | 遇此时辰 | 克性 |
|:-----|:---------|:-----|
| 甲(阳木) | 庚(阳金)时 | 金克木，阳克阳 |
| 乙(阴木) | 辛(阴金)时 | 金克木，阴克阴 |
| 丙(阳火) | 壬(阳水)时 | 水克火，阳克阳 |
| 丁(阴火) | 癸(阴水)时 | 水克火，阴克阴 |
| 戊(阳土) | 甲(阳木)时 | 木克土，阳克阳 |
| 己(阴土) | 乙(阴木)时 | 木克土，阴克阴 |
| 庚(阳金) | 丙(阳火)时 | 火克金，阳克阳 |
| 辛(阴金) | 丁(阴火)时 | 火克金，阴克阴 |
| 壬(阳水) | 戊(阳土)时 | 土克水，阳克阳 |
| 癸(阴水) | 己(阴土)时 | 土克水，阴克阴 |

```python
GAN_YIN = {'甲':'阳','丙':'阳','戊':'阳','庚':'阳','壬':'阳',
           '乙':'阴','丁':'阴','己':'阴','辛':'阴','癸':'阴'}
GAN_WX  = {'甲':'木','乙':'木','丙':'火','丁':'火','戊':'土',
           '己':'土','庚':'金','辛':'金','壬':'水','癸':'水'}
WX_KE   = {'木':'土','土':'水','水':'火','火':'金','金':'木'}

def is_wu_bu_yu_shi(day_gan, hour_gan):
    day_wx = GAN_WX.get(day_gan, '')
    hour_wx = GAN_WX.get(hour_gan, '')
    day_yin = GAN_YIN.get(day_gan, '')
    hour_yin = GAN_YIN.get(hour_gan, '')
    if day_yin == hour_yin and WX_KE.get(hour_wx) == day_wx:
        return True  # 五不遇时，大凶
    return False
```

**判断规则**：五不遇时 → **重大利空信号（权重×3）**，`[!!]`标记

### 维度1：时干宫（事体）—— 权重最高

时干代表"问事的主体"，直接反映该时段的市场状态。

```python
h_god = gods.get(hour_gan_pos, '')   # 八神
h_door = doors.get(hour_gan_pos, '')  # 八门
h_star = stars.get(hour_gan_pos, '')  # 九星
```

**判断规则**：
- 吉神（值符/九天/六合）→ 利好信号
- 凶神（白虎/玄武）→ 利空信号
- 吉门（生门/开门/休门）→ 利好信号
- 凶门（死门/惊门/伤门）→ 利空信号
- 逢空亡 → 利空信号（能量严重减弱）

### 维度2：值符宫（主力趋势）

值符为八神之首，代表主导力量和主力资金意图。

```python
zf_h_pos = ci['zhi_fu_heaven_pos']
zf_door = doors.get(zf_h_pos, '')
```

**判断规则**：
- 值符落宫逢空亡 → 主力虚浮，利空信号
- 值符宫临生门/开门 → 主力积极做多
- 值符宫临死门/惊门 → 主力退缩，利空信号

### 维度3：资金宫（天盘戊）

戊为天盘财星，代表资金流动。天盘戊所落之宫反映资金面状况。

```python
for p, g in hv_stems.items():
    if g == '戊':
        wu_pos = p  # 资金宫
```

**判断规则**：
- 资金宫逢空亡 → 资金不足/流出，利空信号
- 资金宫临生门/开门 → 资金面利好

### 维度4：生门/开门（生机与机会）

生门为三大吉门之首，主生机财利；开门主开畅通达。

**判断规则**：
- 生门逢空亡 → 生机不足，利空信号
- 生门得吉星（天心/天辅/天禽）→ 利好信号

### 维度5：马星宫（波动性）

马星主动，代表突发变动和异动。

```python
ma = ci['ma_palace']  # 马星所在宫
ma_god = gods.get(ma, '')
ma_door = doors.get(ma, '')
```

**判断规则**：
- 马星临九天 → 快速拉升，利好信号
- 马星临九地 → 冲高回落
- 马星临伤门/惊门 → 剧烈波动，利空信号

### 维度6：日干宫（大盘主体）

日干代表大盘/市场本身。

**判断规则**：
- 日干宫逢空亡 → 大盘无力，利空信号
- 日干宫临开门/生门 → 大盘向好，利好信号

## 六、空亡特殊规则

空亡是奇门中最重要的特殊格局之一，**任何关键宫位逢空亡都会导致该宫位能量大幅减弱**：

- 时干逢空 → 事体虚浮，行情不确定
- 值符逢空 → 主力虚浮，缺乏方向
- 资金戊逢空 → 资金不足/流出
- 生门逢空 → 生机不足，上涨无力
- 日干逢空 → 大盘无力

## 七、综合评分与趋势判定

各维度信号按权重计算总分：

| 信号类型 | 标记 | 权重 |
|:---------|:-----|:----:|
| 普通利空信号（凶神/凶门/空亡等） | `[!]` | ×1 |
| **五不遇时（时辰大凶格局）** | `[!!]` | ×3 |

按加权利空分定级：

```
加权利空分 = 0     → 看涨  （无利空信号，强利好）
加权利空分 = 1-2   → 偏多  （总体向好，谨慎乐观）
加权利空分 = 3     → 震荡  （多空平衡，观望为主）
加权利空分 = 4-5   → 偏空  （总体偏弱，注意风险）
加权利空分 >= 6    → 看跌  （强利空，建议回避）
```

## 十一、注意事项

1. **局数计算必须使用拆补法**：根据日干支符头（甲/己日）的地支确定元序，而非简单按节气日+5天计算。
2. **空亡是最强的利空信号**：任何关键宫位逢空都应优先标记。
3. **时干宫的权重大于其他维度**：时干代表事体本身，是判断的核心。
4. **本分析仅供参考，不构成投资建议**：奇门分析是传统术数方法，实际投资需结合基本面、技术面等多维度判断。
5. **夏季用阳遁，局数从1-9**：芒种（阳6/3/9）、夏至（阴9/3/6）等节气定局需核对节气表。
