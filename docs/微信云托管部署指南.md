# 微信云托管 CloudRun 部署指南

## 一、前置条件

1. 已注册微信小程序，并有 AppID
2. 已开通微信云托管（https://cloud.weixin.qq.com）
3. 本地调试已通过

## 二、已创建的部署文件

| 文件 | 说明 |
|------|------|
| `Dockerfile` | Docker 镜像构建文件 |
| `.dockerignore` | 排除不需要的文件 |
| `requirements.txt` | Python 依赖清单 |
| `container.config.json` | 云托管服务配置 |

## 三、部署步骤

### 步骤1：上传代码到 Git 仓库

微信云托管支持从代码仓库自动构建，推荐用 GitHub 或 Gitee：

```bash
# 在项目根目录执行
git init
git add .
git commit -m "奇门遁甲排盘 - 准备云托管部署"
git branch -M main
git remote add origin https://github.com/你的用户名/qimen-api.git
git push -u origin main
```

### 步骤2：在云托管控制台创建服务

1. 打开 https://cloud.weixin.qq.com → 进入「云托管」控制台
2. 点击「创建服务」
3. 填写信息：
   - 服务名称：`qimen-api`
   - 备注：奇门遁甲排盘后端API
4. 点击「创建」

### 步骤3：创建版本（部署）

1. 进入刚创建的服务 → 点击「版本管理」→「新建版本」
2. 选择来源：**代码仓库**（GitHub/Gitee）或 **本地代码上传**
3. 如果选代码仓库：
   - 关联你的 Git 仓库
   - 分支选择 `main`
   - 根目录就是项目根目录（包含 Dockerfile）
4. 如果选本地上传：
   - 将整个项目打包为 zip 上传
5. 构建方式：**Dockerfile**
6. 监听端口：**80**
7. 点击「开始构建」，等待构建完成（约2-3分钟）

### 步骤4：配置服务

构建完成后，在服务设置中确认：

| 配置项 | 值 |
|--------|------|
| 监听端口 | 80 |
| CPU | 0.5 核 |
| 内存 | 1024 MB |
| 实例最小数 | 0（缩容到0省钱） |
| 实例最大数 | 3 |
| 扩缩容策略 | 按 CPU |
| CPU 阈值 | 60% |

### 步骤5：获取服务访问地址

部署成功后，云托管会分配一个**内部访问地址**，格式类似：

```
https://qimen-api-xxxx.xxxxx.tencentcs.com
```

在「服务设置」→「访问路径」中可以看到。

### 步骤6：更新小程序中的 API 地址

将 `miniprogram/app.js` 中的 `apiBase` 改为云托管分配的地址：

```javascript
// app.js
App({
  globalData: {
    apiBase: 'https://qimen-api-xxxx.xxxxx.tencentcs.com/api',
    userInfo: null
  },
  ...
});
```

> **重要**：云托管分配的域名已自动加入小程序合法域名白名单，无需额外配置。

### 步骤7：发布小程序

1. 在微信开发者工具中点击「上传」
2. 填写版本号和备注
3. 登录 https://mp.weixin.qq.com → 「管理」→「版本管理」
4. 提交审核
5. 审核通过后发布

## 四、验证部署

部署完成后，用浏览器或 curl 测试：

```bash
# 健康检查
curl https://你的云托管地址/api/health

# 排盘测试
curl -X POST https://你的云托管地址/api/qimen/chart \
  -H "Content-Type: application/json" \
  -d '{"year":2026,"month":6,"day":6,"hour":22,"minute":5}'
```

预期返回 JSON 排盘数据。

## 五、费用说明

微信云托管按量计费，主要费用：

| 项目 | 说明 |
|------|------|
| CPU/内存 | 按实际运行时间计费 |
| 缩容到0 | 不产生费用（推荐开发阶段设置 minNum=0） |
| 流量费 | 按请求量计费 |

开发阶段费用很低，日常使用每月几元即可。

## 六、常见问题

### Q: 构建失败怎么办？
A: 检查 Dockerfile 是否在项目根目录，requirements.txt 路径是否正确。

### Q: 服务启动后无法访问？
A: 确认 Dockerfile 中 EXPOSE 端口与云托管配置的监听端口一致（都是80）。

### Q: 小程序请求报错"不在合法域名列表"？
A: 云托管分配的域名会自动加入白名单。如果仍报错，在 mp.weixin.qq.com → 「开发」→「开发管理」→「服务器域名」中手动添加。
