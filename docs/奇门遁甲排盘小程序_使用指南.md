# 奇门遁甲排盘微信小程序

## 项目简介

基于已验证的奇门遁甲排盘引擎（`qimen_engine_v2.py`），开发的微信小程序，支持按指定时间进行时家奇门排盘，展示完整的九宫格盘面信息。

## 项目结构

```
sandbox_qimen/
├── qimen_engine_v2.py          # 排盘核心引擎
├── generate_qimen_image.py      # 四柱/节气/局数计算 + 图片生成
├── backend/                     # 后端Flask API服务
│   ├── app.py                   # API主程序
│   ├── requirements.txt         # Python依赖
│   └── gunicorn.conf.py         # 生产部署配置
├── miniprogram/                 # 微信小程序前端
│   ├── app.js                   # 小程序入口
│   ├── app.json                 # 小程序配置
│   ├── app.wxss                 # 全局样式
│   ├── sitemap.json
│   └── pages/
│       ├── index/               # 首页（时间选择）
│       ├── chart/               # 排盘结果页（九宫格展示）
│       └── about/               # 关于页面
├── scripts/
│   └── deploy_backend.py        # 后端部署脚本
└── docs/                        # 排盘规则文档
```

## 快速开始

### 1. 后端API部署

#### 本地开发

```bash
# 1. 创建虚拟环境
python -m venv .venv

# 2. 激活虚拟环境
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

# 3. 安装依赖
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r backend/requirements.txt

# 4. 启动API服务
python backend/app.py
```

API默认运行在 `http://127.0.0.1:5000`。

#### 生产部署（Linux服务器）

```bash
# 安装gunicorn
pip install gunicorn

# 启动服务
gunicorn -c backend/gunicorn.conf.py backend.app:app
```

建议配合 Nginx 反向代理使用：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /api/ {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 2. 小程序配置

1. 打开 **微信开发者工具**
2. 导入项目，选择 `miniprogram/` 目录
3. 修改 `miniprogram/app.js` 中的 `apiBase`：
   ```js
   apiBase: 'http://127.0.0.1:5000/api'  // 本地开发
   // 或
   apiBase: 'https://your-domain.com/api'  // 生产环境
   ```
4. 在开发者工具中预览调试

### 3. API接口说明

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/qimen/chart` | POST | 排盘（传入年月日时分） |
| `/api/qimen/now` | GET | 获取当前时间排盘 |
| `/api/hour_zhi?hour=22` | GET | 根据小时获取时辰地支 |

## 微信小程序上线流程

### 第一步：注册微信小程序账号

1. 访问 https://mp.weixin.qq.com/
2. 点击「立即注册」→ 选择「小程序」
3. 填写邮箱、密码完成注册
4. 完成主体信息认证（个人或企业）

### 第二步：配置服务器域名

1. 登录微信公众平台 → 开发管理 → 开发设置
2. 在「服务器域名」中添加你的API域名：
   - request合法域名：`https://your-domain.com`
3. 注意：必须使用HTTPS，不支持HTTP（开发时可在开发者工具中勾选「不校验合法域名」）

### 第三步：获取AppID

1. 在开发设置中查看 AppID
2. 在微信开发者工具中填入该 AppID

### 第四步：提交审核

1. 在开发者工具中点击「上传」
2. 登录微信公众平台 → 版本管理 → 提交审核
3. 填写功能页面信息，提交审核
4. 审核通过后发布上线

### 审核注意事项

- 小程序内容需符合微信运营规范
- 确保排盘功能正常运行，无崩溃
- 在「关于」页面添加免责声明
- 类目建议选择：工具 > 信息查询

## 排盘规则说明

本程序依据以下规则文档实现：

- `docs/排盘规则.md` — 总体排盘规则
- `docs/八门的排盘方法.md` — 八门排布方法
- `docs/天盘八神和地盘八神的排盘方法.md` — 八神排布方法
- `docs/定局规则.md` — 节气定局规则
- `docs/寄宫原则和方法.md` — 寄宫规则

**核心规则：**
- 地盘：从局数宫起，阳遁顺飞/阴遁逆飞布三奇六仪
- 天盘：值符随时干，九星永远顺时针排布
- 八门：值使随时支，按旬内偏移走宫位数字序
- 八神：小值符随大值符，阳遁顺时针/阴遁逆时针
- 寄宫：采用最常用的寄坤宫法
