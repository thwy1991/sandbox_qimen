奇门遁甲时盘转盘法的排盘，以下会按天盘、八门、九星、八神的排法来分别说明，最后再讲寄宫的原则与方法。



\---



\## 一、排盘的总顺序



转盘奇门的排盘顺序是固定的：\*\*先布地盘 → 再布天盘 → 再布人盘（八门）→ 最后布神盘（八神）\*\*，这个顺序符合宇宙天地人神的层次关系。



地盘（即根据局数把三奇六仪布入九宫，固定不动）完成后，开始转动各盘。



\---



\## 二、天盘的排法（九星及其所带三奇六仪）



天盘由九星及其所携带的三奇六仪组成。天盘的转动遵循\*\*“值符随时干”\*\*的原则。



\### 1. 九星的固定顺序



九星在九宫中的原始固定位置如下：



| 九星 | 原始宫位 |

| :--- | :--- |

| 天蓬星 | 坎一宫 |

| 天芮星 | 坤二宫（与天禽星配对） |

| 天冲星 | 震三宫 |

| 天辅星 | 巽四宫 |

| 天禽星 | 中五宫 |

| 天心星 | 乾六宫 |

| 天柱星 | 兑七宫 |

| 天任星 | 艮八宫 |

| 天英星 | 离九宫 |



转盘奇门中九星的排布顺序是\*\*天蓬 → 天任 → 天冲 → 天辅 → 天英 → 天芮（与天禽配对）→ 天柱 → 天心\*\*，\*\*不论阴遁、阳遁，永远顺时针旋转布列九宫\*\*。



\### 2. 找值符



值符是当天当值的九星。确定方法如下：

\- 先找到用事时辰的\*\*旬首\*\*（如甲子旬、甲戌旬等）

\- 查看旬首隐藏在地盘哪个六仪之下，该六仪所在的宫位

\- 此宫位对应的\*\*固定盘九星\*\*就是值符



例如：时柱庚辰属于甲戌旬，甲戌藏在六仪已之下，己落在兑七宫，兑七宫的本位星是天柱星，那么\*\*值符 = 天柱星\*\*。



\### 3. 天盘转动



天盘转动的核心口诀是\*\*“值符随时干”\*\*——将值符转到时辰的天干在地盘所在的宫位。



\*\*具体步骤：\*\*

1\. 找出时干（时辰的天干）在地盘上所落的宫位

2\. 将值符（九星）转到该宫位

3\. 其余九星按\*\*顺时针方向\*\*依次填入其他宫位

4\. 将各九星\*\*原来固定宫位\*\*的地盘奇仪一起带入，写在地盘天干的上方，即为天盘天干



\*\*举例：\*\* 庚辰时，时干庚落艮八宫，值符天柱星从兑七宫转到艮八宫，然后天心星落震三宫，天蓬星落巽四宫……顺时针依次排满九宫。





\## 三、八门的排法（人盘）



八门代表人和，其排布遵循\*\*“值使随时支”\*\*的原则。



\### 1. 八门的固定顺序



八门是\*\*休门、生门、伤门、杜门、景门、死门、惊门、开门\*\*。\*\*不论阴遁还是阳遁，八门永远顺时针旋转布列\*\*。



八门在九宫中的原始固定位置如下：



| 八门 | 固定宫位 |

| :--- | :--- |

| 休门 | 坎一宫 |

| 生门 | 艮八宫 |

| 伤门 | 震三宫 |

| 杜门 | 巽四宫 |

| 景门 | 离九宫 |

| 死门 | 坤二宫 |

| 惊门 | 兑七宫 |

| 开门 | 乾六宫 |



\### 2. 找值使



值使是当天当值的八门。确定方法与值符类似：

\- 找到旬首所在宫位

\- 该宫位对应的\*\*固定盘八门\*\*就是值使



例如：甲戌旬首落在兑七宫，兑七宫的固定门是惊门，则\*\*值使 = 惊门\*\*。



\### 3. 八门转动



八门转动的核心口诀是\*\*“值使随时支”\*\*——将值使转到时辰的地支在地盘所在宫位。



\*\*具体步骤：\*\*

1\. 从旬首所在宫位起，依次数到时辰的地支所在宫位

2\. 阳遁顺数，阴遁逆数

3\. 将值使门布到该宫位

4\. 其余八门从该宫位开始，\*\*顺时针\*\*依次排入其余宫位



\*\*举例：\*\* 甲戌旬首在兑七宫（序数7），时辰为庚辰时，阳遁顺数：兑七（甲戌）→ 艮八（乙亥）→ 离九（丙子）→ 坎一（丁丑）→ 坤二（戊寅）→ 震三（己卯）→ 巽四（庚辰），值使惊门落在巽四宫。





\## 四、八神的排法（神盘）



八神代表神助，是排盘的最后一层。



\### 1. 八神的固定顺序



八神的固定顺序是：\*\*值符 → 螣蛇 → 太阴 → 六合 → 白虎 → 玄武 → 九地 → 九天\*\*。



在转盘奇门中，这个顺序是\*\*不变的\*\*，不管是阳遁还是阴遁，八神的排列顺序都一样。



> \*\*注：\*\* 古时神盘被称为“八诈盘”，阴遁时白虎换为勾陈、玄武换为朱雀。因白虎与勾陈、玄武与朱雀的奇门取象相近，如今只保留八神。



\### 2. 八神的排布



八神排布的核心原则是\*\*“小值符随大值符”\*\*——八神中的值符（小值符）永远跟随天盘九星的值符（大值符）。



\*\*区别在于方向：\*\*

\- \*\*阳遁\*\*：八神\*\*顺时针\*\*排布

\- \*\*阴遁\*\*：八神\*\*逆时针\*\*排布



具体步骤：

1\. 值符（小值符）落在大值符（天盘值符星）所在的宫位

2\. 其余七神从该宫位的下一宫开始，阳遁按顺时针顺序（符 → 蛇 → 阴 → 合 → 虎 → 武 → 地 → 天）依次排入各宫，阴遁则按逆时针顺序排入





\## 五、寄宫的原则和方法



\### 1. 为什么要寄宫？



九宫有九个格子，但八门和八神都只有八个，八门和八神分布在周围八个宫，唯独中五宫无门无神。然而，任何一个宫都必须星、门、神、仪齐全。因此，需要将中五宫的内容（天禽星及所临的奇仪）“寄”到周围某一宫内，与该宫共用同一个八门和八神。



\### 2. 寄宫的几种方法



目前关于寄宫的方法主要有以下几种流派：



| 流派 | 规则 | 依据 |

| :--- | :--- | :--- |

| \*\*寄坤宫法\*\* | 中宫永远寄于坤二宫 | 坤为地为母，为万物之源；中宫天禽星代表中央皇帝，坤宫代表母亲，以孝道治天下 |

| \*\*阳遁寄艮、阴遁寄坤法\*\* | 冬至后阳遁寄艮八宫，夏至后阴遁寄坤二宫 | 阳生阴死的原理 |

| \*\*随节气寄宫法\*\* | 中宫随节气变化而分寄八个宫 | 随乎时令，节气流转 |



三种方法的具体规则如下：



\*\*① 寄坤宫法（最简单、最常用）\*\*

\- 中五宫的天禽星与坤二宫的天芮星捆绑起来

\- 天盘天芮星落到哪个宫，天盘天禽星就跟着落在哪个宫

\- 当前学转盘奇门时，\*\*问事局多采用此法，终身局多用寄二八宫法\*\*



\*\*② 阳遁寄艮、阴遁寄坤法\*\*

\- 阳遁（冬至→芒种）：寄艮八宫

\- 阴遁（夏至→大雪）：寄坤二宫



\*\*③ 随节气寄宫法（以每三个节气为一组）\*\*

\- 冬至、小寒、大寒三个节气 → 寄坎一宫

\- 立春、雨水、惊蛰三个节气 → 寄艮八宫

\- 春分、清明、谷雨三个节气 → 寄震三宫

\- 立夏、小满、芒种三个节气 → 寄巽四宫

\- 夏至、小暑、大暑三个节气 → 寄离九宫

\- 立秋、处暑、白露三个节气 → 寄坤二宫

\- 秋分、寒露、霜降三个节气 → 寄兑七宫

\- 立冬、小雪、大雪三个节气 → 寄乾六宫



\### 3. 各流派的取舍



不同的流派各有其使用技巧和依据，不能说哪个完全对或完全错，各流派都有其传承和验证的基础，都值得学习和借鉴。目前转盘奇门中，\*\*寄坤宫法最为普遍\*\*，相对简单易懂，初学者可以从这一方法入手。





\## 六、转盘法口诀速记



以下口诀概括了转盘奇门排盘的精要：



| 口诀 | 解释 |

| :--- | :--- |

| \*\*“地盘戊己起宫，阳顺阴逆布仪”\*\* | 先布地盘，根据局数确定戊的位置，阳遁顺布六仪逆布三奇，阴遁相反 |

| \*\*“值符随时干转，天盘顺行不停”\*\* | 值符星转到时干所在宫，其余九星顺时针依次排列 |

| \*\*“值使随时支迁，人盘顺排八门”\*\* | 值使门转到时支所在宫，其余八门顺时针依次排列 |

| \*\*“小符追随大符，阳顺阴逆布神”\*\* | 八神的值符跟随天盘值符星，阳遁顺时针布八神，阴遁逆时针布 |

| \*\*“中宫五号无门，寄入坤宫同行”\*\* | 中五宫无门无神，将其内容寄到坤二宫处理 |
