好的，以下单独总结奇门遁甲转盘法中\*\*八门（人盘）\*\* 的排盘方法，不涉及其他盘。



\---



\## 一、八门的固定顺序与原始位置



八门共有八个：\*\*休、生、伤、杜、景、死、惊、开\*\*。  

在未转动前，它们固定分布在九宫（中五宫无门）中：



| 宫位 | 八门 |

| :--- | :--- |

| 坎一宫 | 休门 |

| 艮八宫 | 生门 |

| 震三宫 | 伤门 |

| 巽四宫 | 杜门 |

| 离九宫 | 景门 |

| 坤二宫 | 死门 |

| 兑七宫 | 惊门 |

| 乾六宫 | 开门 |



\*\*不论阳遁还是阴遁，八门的排列顺序始终顺时针\*\*：  

休 → 生 → 伤 → 杜 → 景 → 死 → 惊 → 开。



\---



\## 二、八门排盘的核心原则



口诀：\*\*“值使随时支”\*\*



\- \*\*值使\*\*：当前时辰的值班八门（即当值的门）。

\- \*\*时支\*\*：时辰的地支（子、丑、寅……亥）。

\- 将值使门转到时支所落的宫位，其余八门按固定顺序顺时针布入其余各宫。



\---



\## 三、第一步：找出值使门



值使门的查找依赖\*\*旬首\*\*。



\### 1. 确定旬首

一个时辰属于甲子、甲戌、甲申、甲午、甲辰、甲寅六旬之一。例如：

\- 甲子、乙丑、丙寅……癸酉 → 甲子旬

\- 甲戌、乙亥……癸未 → 甲戌旬，依此类推。



\### 2. 找出旬首所在地盘宫位

旬首（甲子、甲戌等）隐藏在地盘六仪之下。查看地盘，找到该旬首所在宫位。



例如：甲戌旬，甲戌藏于己，己落在兑七宫，则旬首在兑七宫。



\### 3. 该宫位的固定八门即为值使门

兑七宫的固定门是惊门 → \*\*值使 = 惊门\*\*。



\---



\## 四、第二步：将值使门转到时支所在宫位



口诀：\*\*“阳遁顺数，阴遁逆数”\*\*，从旬首所在宫位起数至时支。



\### 具体步骤：

1\. 确定旬首所在宫位的\*\*数字序号\*\*（从坎一宫=1，坤二=2，震三=3，巽四=4，中五=5，乾六=6，兑七=7，艮八=8，离九=9）。

2\. 从旬首宫位起数（首位数第1位），阳遁顺时针数，阴遁逆时针数，数到时支的位置。

3\. 该位置即为值使门落宫。



\*\*举例（阳遁顺数）：\*\*

\- 局数：阳遁

\- 旬首：甲戌，落在兑七宫（数字7）

\- 时辰：庚辰时，时支为辰（地支序数：子1、丑2……辰5）

\- 从兑七宫开始顺数：  

&#x20; 兑7（甲戌第1）→ 艮8（乙亥第2）→ 离9（丙子第3）→ 坎1（丁丑第4）→ 坤2（戊寅第5）→ 震3（己卯第6）→ 巽4（庚辰第7）

\- 到第7位时落在巽四宫 → \*\*值使门（惊门）落在巽四宫\*\*。



\*\*举例（阴遁逆数）：\*\*

\- 局数：阴遁

\- 旬首：甲子，落坎一宫（数字1）

\- 时辰：丁卯，时支卯（地支序数4）

\- 从坎一宫开始逆数：  

&#x20; 坎1（甲子第1）→ 离9（乙丑第2，逆时针）→ 艮8（丙寅第3）→ 兑7（丁卯第4）

\- 到第4位落在兑七宫 → \*\*值使门落在兑七宫\*\*。



\---



\## 五、第三步：排布其余七门



值使门落宫确定后，其余七门按\*\*顺时针顺序\*\*（休→生→伤→杜→景→死→惊→开）依次填入其他八个宫位（中五宫不填门）。



\### 方法：

\- 将值使门写在它落宫的旁边。

\- 从值使门的顺时针下一个门开始，按顺时针方向依次填入下一宫、再下一宫……填满八个宫为止。



\*\*举例接上：\*\*  

值使惊门落在巽四宫，则：

\- 巽四宫：惊门

\- 顺时针下一宫（离九宫）：开门

\- 再下一宫（坤二宫）：休门

\- 再下一宫（兑七宫）：生门

\- 再下一宫（乾六宫）：伤门

\- 再下一宫（坎一宫）：杜门

\- 再下一宫（艮八宫）：景门

\- 再下一宫（震三宫）：死门



（注意：顺序是固定的，但起始点不同，每个宫的八门会按顺时针循环。）

\## 六、八门排盘速查表（落宫循环）



为了方便，可以记住八门的循环顺序：  

\*\*休1 → 生2 → 伤3 → 杜4 → 景5 → 死6 → 惊7 → 开8 → 休1……\*\*



将值使门的序号对应到落宫，然后按宫位顺时针+1序号即可。

\## 七、注意事项



1\. \*\*中五宫无门\*\*：永远不布八门。

2\. \*\*八门次序固定\*\*：永远顺时针循环，不因阴阳遁而改变方向（方向改变只影响值使的“数步”过程，但不影响八门自身顺时针布列）。

3\. \*\*值使的确定\*\*：依赖于地盘旬首位置，因此必须先正确布好地盘。

4\. \*\*实际排盘\*\*：先排天盘九星，再排八门（人盘），最后排八神。



\---



以上就是\*\*转盘奇门八门排盘\*\*的完整独立方法。只要按“找旬首→定值使→数时支→布八门”四步操作，即可正确排出人盘。
